A few things to know about your IP address

Your IP address helps internet services route traffic. The information associated with it has useful limits.

What Is a Public IP Address?

A public IP address is the address external internet services see for a network connection. It may represent a router, a VPN exit server, or a shared connection rather than one individual device or person. Learn more in our guide to IP addresses.

What Information Can an IP Address Reveal?

An IP address can provide clues about the network, internet provider, and approximate geographic area associated with a connection. On its own, it generally does not reveal a person's exact home address or reliably establish their identity.

What Is the Difference Between IPv4 and IPv6?

IPv4 uses 32-bit addresses, usually written as four numbers separated by dots. IPv6 uses 128-bit addresses and hexadecimal groups separated by colons, providing a much larger address space. Both are used to identify network interfaces and route internet traffic.

Does a VPN Change My Public IP Address?

A VPN normally causes external services to see the VPN server's public IP address instead of the connection's original public IP when traffic is routed through the VPN. Results depend on the VPN configuration and how traffic is routed. Read our VPN guide.

Is IP Geolocation Exact?

No. IP geolocation is an estimate based on databases and network information. VPNs, proxies, mobile networks, ISP routing, and outdated or incomplete databases can affect the result. It should not be treated as proof of someone's exact location.

How Does DNS Fit In?

DNS translates domain names into information computers use to locate services on a network. It works alongside IP addressing, but it serves a different purpose. See our explanation of how DNS works.
