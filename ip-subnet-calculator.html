Networking basics

Understanding IPv4 subnetting

Use these quick explanations to understand what the calculator's results mean.

What Is a Subnet?

A subnet is a smaller logical network within a larger IP address space. Dividing a network into subnets helps organize devices, manage address ranges, and control how traffic moves between network segments.

What Is CIDR Notation?

CIDR notation adds a slash and a number to an IP address, such as /24. The number tells you how many of the 32 IPv4 bits identify the network; the remaining bits identify addresses within that subnet.

What Is a Subnet Mask?

A subnet mask is a 32-bit value written in dotted-decimal form, such as 255.255.255.0. Its network bits are set to 1 and its host bits to 0, showing which part of an IPv4 address identifies the subnet.

What Are Network and Broadcast Addresses?

In a conventional IPv4 subnet, the network address identifies the subnet and the broadcast address is used to address all hosts on that subnet. A /31 point-to-point link is a special case: under RFC 3021, both addresses are endpoint addresses and there is no conventional broadcast address on the link.

How Many Usable Hosts Does a Subnet Support?

For prefixes from /0 through /30, the conventional usable-host count is the total number of addresses minus two for the network and broadcast addresses. A /31 has two usable point-to-point endpoints. A /32 contains one address and represents a single host route.
