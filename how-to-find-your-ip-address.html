The quick answer

To find your public IP address, open a browser and visit the Cloudflare Trace endpoint, then look for the ip= line. To find your private IP address, open your device's network settings. On Windows, you can also run ipconfig and check the active adapter's IPv4 Address. The right method depends on which address you need.

First, Understand Which IP Address You Need

Finding your IP address depends on two things: whether you need your public or private IP address and which device you're using.

A public IP address is the publicly visible source address associated with your internet connection. Websites and online services can generally see this address when you connect to them. However, a VPN, proxy, or carrier-grade NAT (CGNAT) can affect which address appears and whether it belongs directly to your router.

A private IP address identifies a network interface within a private network, such as your home or office Wi-Fi. Your router commonly assigns these addresses to your computer, phone, printer, and other connected devices.

You might need your public IP address to check what websites can see or to troubleshoot an internet connection. You might need your private IP address to connect a printer, configure a local network, or diagnose a device-to-device connection problem.

Common private IPv4 ranges include:

  • 10.0.0.0 to 10.255.255.255
  • 172.16.0.0 to 172.31.255.255
  • 192.168.0.0 to 192.168.255.255

These ranges are reserved for private use, as documented by the Internet Assigned Numbers Authority (IANA) and RFC 1918. Not every address beginning with 172 is private; it must fall within the specific range above.

You may also encounter IPv6 addresses, which use hexadecimal characters separated by colons instead of the dotted-decimal format used by IPv4. Depending on your network, a device can display both IPv4 and IPv6 addresses, sometimes with multiple entries for different purposes. For more detail, read our guide to public vs. private IP addresses.

The Fastest Way to Find Your Public IP Address

If you want to know which IP address an external service sees, you don't need to search through your device's settings. You can use a public IP-checking service directly in your browser.

Steps to check your public IP

  1. Open a web browser on your computer, smartphone, or tablet.
  2. Visit the Cloudflare Trace endpoint.
  3. Look for the line beginning with ip=.
  4. The value after the equals sign is the IP address observed by Cloudflare for that request.

The endpoint displays technical information in plain text rather than a conventional IP-checker interface. Cloudflare also provides a privacy policy explaining how it handles information, including IP addresses.

If you are connected to a VPN, the result will commonly show the VPN's public-facing exit IP address rather than the address your internet provider would otherwise expose. The exact result depends on your connection and routing configuration.

The address can differ from the one shown in your device settings because those settings usually show an address assigned to a particular network interface, while an external service observes the connection reaching its servers. Checking one address is not a complete VPN leak test and does not guarantee anonymity.

How to Find Your IP Address on Windows

Windows 11 provides a straightforward way to find your private IP address through Settings. You can also use Command Prompt to display more network information.

Method 1: Use Windows Settings

  1. Open Start and select Settings.
  2. Select Network & internet.
  3. If you're connected through Wi-Fi, select Wi-Fi and open the properties of your connected network. If you're using a wired connection, select Ethernet.
  4. Find the IPv4 address field in the network information.

If the network provides IPv6, related IPv6 information may also appear in the network details. The address listed here is normally the private IP address assigned to your computer's active network interface on a typical home or office network.

Method 2: Use Command Prompt

  1. Open the Start menu.
  2. Search for Command Prompt and open it.
  3. Type the following command and press Enter:
ipconfig
  1. Find the section corresponding to your active network adapter, such as Wireless LAN adapter Wi-Fi or Ethernet adapter Ethernet.
  2. Look for IPv4 Address and any relevant IPv6 entries.

You will usually also see a field labeled Default Gateway. Your computer's IPv4 address identifies its network interface, while the default gateway is normally the local router or another device that forwards traffic to other networks.

If you use a VPN, the output may also include a virtual network adapter. Select the appropriate adapter for the address you need rather than assuming the first entry is always correct. The exact Settings layout can vary between Windows versions, but ipconfig is a widely available alternative.

How to Find Your IP Address on a Mac

On current macOS versions, you can find your local IP address through System Settings. The relevant network details depend on whether you're using Wi-Fi or Ethernet.

Steps to find your Mac's private IP address

  1. Open the Apple menu in the upper-left corner.
  2. Select System Settings.
  3. Click Network in the sidebar.
  4. Select your active network connection, such as Wi-Fi or Ethernet.
  5. Click Details.
  6. Open TCP/IP to view the IP configuration.

Look for the IPv4 address field. If IPv6 is enabled, you may also see IPv6 address information. The TCP/IP settings can also display the Router address, which is useful if you are trying to access your router's administration page.

Make sure you select the connection you are actually using. If both Wi-Fi and Ethernet are available, the addresses associated with them may differ. Menu labels and their placement can vary slightly across macOS versions. See Apple's guide to changing TCP/IP settings on Mac.

How to Find Your IP Address on Android

Android provides network information through Settings, but the exact menu layout depends on the phone manufacturer, Android version, and device interface. The following is a common approach based on the network settings used on Google Pixel devices.

Steps to find your Android phone's private IP address

  1. Open Settings.
  2. Select Network & internet.
  3. Tap Internet.
  4. Find your connected Wi-Fi network and open its details. Depending on your phone, this may involve tapping the network name or its settings icon.
  5. Look for IP address, Network details, or an equivalent information section.

Your device's private IPv4 address may appear alongside IPv6 information and other network settings. If you cannot find the IP address, try searching for IP address in the Settings search bar. Some manufacturers place the information under an Advanced section or use different labels.

Make sure you are reading the device's own IP address rather than the Gateway or router address. The gateway is the address used to reach other networks and is not normally the phone's own address.

What if you're using mobile data?

The instructions above focus on Wi-Fi. When you use mobile data, your phone connects through your cellular provider, and the relevant network settings may be different.

Mobile providers frequently use carrier-grade NAT, which allows multiple customers to share a public IPv4 address. As a result, the address visible to a website may not be assigned directly to your phone. To check the public-facing address of your mobile connection, turn off Wi-Fi, make sure mobile data is working, and visit the Cloudflare Trace endpoint.

How to Find Your IP Address on an iPhone or iPad

Apple provides the private IP address for a Wi-Fi connection in the network's settings. The same general procedure applies to current iOS and iPadOS interfaces.

Steps to find your iPhone or iPad's private IP address

  1. Open Settings.
  2. Tap Wi-Fi.
  3. Find the network you're currently connected to.
  4. Tap the information button (ⓘ) beside the network name.
  5. Look under the IPv4 address information for IP Address.

If IPv6 is enabled, the details screen may also display IPv6 addresses. You may see the router's address in the same network details screen. The address shown here normally identifies your device on that Wi-Fi network; it is not necessarily the public IP address visible to websites.

How to check your public IP on an iPhone

  1. Open Safari or another browser.
  2. Visit the Cloudflare Trace endpoint.
  3. Look for the ip= field.

If you use a VPN or a service such as iCloud Private Relay, the address observed by a website may differ from the address associated with your normal internet connection.

How to Find Your Router's IP Address

Your router has its own local network address, which is different from the address assigned to your computer or phone. You may need this address to open your router's administration interface, troubleshoot a connection, or configure certain local network settings.

On Windows

  1. Open Command Prompt.
  2. Run ipconfig.
  3. Find the active Wi-Fi or Ethernet adapter.
  4. Look for Default Gateway.

On a typical home network, the default gateway is the router's local IP address.

On a Mac

  1. Open Apple menu → System Settings.
  2. Select Network.
  3. Select your active Wi-Fi or Ethernet connection.
  4. Click Details → TCP/IP.
  5. Find the Router field.

Apple's Mac network settings documentation explains where to find these TCP/IP details.

Why your router's address may be different

Some routers use addresses such as 192.168.0.1 or 192.168.1.1, but these are examples, not universal defaults. Your router may use another private address, including one from the 10.x.x.x range or the private 172.16.x.x through 172.31.x.x range.

Also, distinguish the router's local gateway address from its internet-facing address. The former is used within the local network; the latter, when a public address is assigned directly, is associated with communication beyond that network. Some internet providers use CGNAT, so the address observed on the internet may not be directly assigned to the router.

Public IP vs. Private IP: Why the Results Are Different

Finding different IP addresses on your computer, phone, router, and an external website is normal. The results can differ for several reasons:

  • Local addresses and NAT: In a typical home IPv4 network, the router assigns private IP addresses to individual devices. Network Address Translation (NAT) allows those devices to access the internet through a shared public-facing IPv4 address.
  • Different network interfaces: A device may have separate addresses for Wi-Fi, Ethernet, a VPN, and other virtual or physical interfaces.
  • Wi-Fi vs. mobile data: Your Wi-Fi connection and cellular connection use different network paths. Their public-facing addresses may be different.
  • VPNs and proxies: An external website will commonly see the address of the VPN exit server or other intermediary that sends the request.
  • IPv4 and IPv6: Your network may support both protocols. A website or IP-checking service may observe IPv4 or IPv6 depending on its connectivity and the route used.

These differences do not automatically indicate a problem. They reflect how network addressing and routing work. For a more detailed comparison, see public vs. private IP addresses. If you're investigating why a VPN changes the address that websites see, our article What Is a VPN? provides more background.

What If You Cannot Find Your IP Address?

If the expected address does not appear, work through the following checks:

  • Your device is disconnected. Connect to Wi-Fi or Ethernet, or confirm that mobile data is enabled and working. Then reopen the network details.
  • You're viewing the wrong interface. Check which connection is active. VPN adapters, virtual interfaces, and disconnected network adapters can display additional addresses.
  • You're using mobile data instead of Wi-Fi. The Wi-Fi settings screen may not describe your current internet connection. Use a browser-based IP check to see the address observed by an external service.
  • The menus do not match these instructions. Search your device's Settings for IP address or consult the manufacturer's official documentation.
  • You've confused the gateway with your device's address. On Windows, compare IPv4 Address with Default Gateway. On a Mac, compare the IP address with Router.
  • A VPN is enabled. Visit the IP-checking service while connected, then compare the result with what you see when the VPN is disconnected, if appropriate. Remember that disconnecting changes the connection being tested.
  • You see an unfamiliar IPv6 address. IPv6 addresses use colons and hexadecimal characters. Some devices also show link-local or other interface-specific IPv6 addresses, which are not necessarily the address an external website sees.

Avoid changing advanced network settings simply because two addresses are different. First, confirm that you have identified the correct device, interface, and type of IP address.

Is It Safe to Share Your IP Address?

An IP address is not generally equivalent to a password or account credential, but sharing it publicly can reveal information about your network connection.

Depending on the address and available lookup data, someone may be able to identify your internet service provider or estimate your general geographic region. Geolocation is not the same as identifying an exact home address or confirming a person's identity.

An exposed public IP address can also be relevant to certain security risks, depending on the network configuration, firewall rules, and services accessible from the internet. A public IP address by itself does not prove that a device is vulnerable.

For sensible protection:

  • Avoid publishing connection details unnecessarily in public forums or screenshots.
  • Keep your operating system, applications, and router firmware updated.
  • Use strong administrative credentials for your router.
  • Maintain appropriate firewall and network security settings.

A VPN can change the public-facing address seen by many websites, depending on how traffic is routed. However, it does not guarantee complete anonymity or prevent every form of online tracking. To understand how VPN connections work and what they can and cannot protect, read What Is a VPN?

Frequently Asked Questions

How do I find my IP address quickly?

To find your public-facing IP address, open a browser and visit the Cloudflare Trace endpoint. Look for the ip= field. For your private IP address, open your device's network settings.

Can my IP address change?

Yes. Public and private IP addresses can change depending on how they are assigned and how your network is configured. A dynamically assigned address may remain unchanged for a long period or change after a network event, lease renewal, or provider reassignment.

Does my IP address change when I use a VPN?

A VPN commonly changes the public-facing IP address that websites see by routing traffic through a VPN server. The exact result depends on the VPN configuration, network path, protocol, and any other services or interfaces involved.

Can I find my IP address without installing an app?

Yes. You can view a public-facing IP address using a browser-based checking service. Windows, macOS, Android, iOS, and iPadOS also provide built-in network settings for viewing local address information.

Is my IP address the same as my router's IP address?

Not necessarily. Your computer or phone normally has its own private IP address on the local network. The router has a separate local address, often shown as the default gateway. A public-facing address may be shared by several devices, and an ISP may also use carrier-grade NAT.

Conclusion

Finding your IP address is straightforward once you know which address you need. Use a browser-based service to check the public-facing address seen by an external website, or open your device's network settings to find its local IP address.

Windows, Mac, Android, iPhone, and iPad each provide ways to view their network details, although the exact menu paths can vary. If the results differ, check whether you're comparing a public address, a private address, a router address, or an IPv6 address.
