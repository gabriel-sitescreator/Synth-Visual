The quick answer

An IP address is a numerical label used by Internet Protocol to identify the source and destination of data sent across networks. Public and private IP addresses have different roles, and IPv4 and IPv6 are two versions of the protocol. An IP address can provide information about a network connection, but it does not automatically reveal the identity or exact location of the person using it.

An IP address is a numerical label assigned to a network interface or endpoint so Internet Protocol (IP) data can identify its source and destination and travel across networks. Put simply, when people ask what is an IP address, they are asking about one of the basic addressing systems that allows devices to communicate over the internet.

Everyday activities such as browsing a website, watching a video, or sending a message depend on network communication. IP addresses help data reach the appropriate destination, whether that destination is a server on the internet or another device on a local network.

There are different types of IP addresses. Public and private IP addresses serve different roles, while IPv4 and IPv6 are two versions of the Internet Protocol. Some addresses remain stable, while others can change over time.

Understanding these differences makes it easier to learn how the internet works, what an IP address can reveal, and how to find your own.

What Does IP Address Mean?

IP stands for Internet Protocol, a set of rules that governs how data is addressed and delivered across interconnected networks. An IP address is one of the essential pieces of information used by this protocol.

When a device sends data, IP addressing helps identify where the data originated and where it should go. Information travels in units called packets, which carry addressing information that allows network equipment to forward them toward their destinations.

Think of an IP address as a mailing address for network communication. A postal address helps a delivery service direct a package to the right place. Similarly, IP addressing helps networks direct data packets toward an intended endpoint.

The analogy is not perfect: IP addresses are not necessarily permanent, and network traffic may pass through several routers before reaching its destination.

An IP address also does not automatically identify a specific person. It identifies an endpoint for network communication, and the relationship between that endpoint and a device, connection, or person depends on the network setup.

For example, a home router may give your laptop a private IP address while using a public IP address for internet communication. Websites generally see the public source address used for that connection, not the laptop's private address.

How Does an IP Address Work?

IP addressing helps data move between networks. Here is what happens when you open a website on your laptop or smartphone.

1

Your device connects to a network

Your laptop joins a home Wi-Fi network, for example, and receives the network configuration needed to communicate.

2

Your device uses an appropriate IP address

It may have a private IP address for communication within the home network and use a public IP address through the router when accessing the internet.

3

Your device requests information

When you open a website, your device sends network traffic toward the destination server. The packets contain source and destination IP addresses.

4

Routers forward the packets

Your home router sends traffic toward your internet service provider (ISP), and routers across the internet forward packets according to routing information.

5

The destination responds

The server processes the request and sends response data toward the source. The network routes those packets back through the relevant connections.

In a typical home IPv4 setup, the router often uses a technique called Network Address Translation (NAT) to allow devices with private addresses to communicate with the internet through a shared public address.

Another important part of this process is the Domain Name System (DNS). When you enter a website address such as example.com, DNS helps your device discover the IP address associated with that domain name. IP addressing and DNS work together, but they are not the same thing: DNS helps resolve names, while IP addressing supports the delivery of network packets.

The specific route and addressing details depend on the destination and how the network is configured.

What Is a Public IP Address?

A public IP address is an address used for communication across the public internet when the address is globally routable. It allows internet-facing services and networks to exchange data with other networks.

An internet service provider may assign a public IP address to your home router or connection. The assignment can be static or dynamic, depending on the provider and service.

In a common home network, your laptop, smartphone, and smart TV may all connect to the internet through the same public IPv4 address. The router uses NAT to manage traffic between the devices' private addresses and the shared public address.

This means that a public IP address does not necessarily belong to one individual device or uniquely identify one person.

Some providers also use Carrier-Grade NAT (CGNAT), which allows multiple customers to share a public IPv4 address. In this situation, the public address may represent traffic from several separate customer connections.

Websites and online services can generally see the public source IP address used by a connection. However, the address they observe may belong to a VPN server, proxy, corporate gateway, or other intermediary rather than the user's original internet connection.

What Is a Private IP Address?

A private IP address is used within a private network, such as a home, school, or office network. Private IPv4 addresses allow connected devices to communicate without requiring each device to have its own globally routable public IPv4 address.

Common examples include:

  • 192.168.1.20
  • 10.0.0.25
  • 172.16.0.10

These examples come from address ranges reserved for private use by RFC 1918.

Consider a home network with a laptop, smartphone, and printer. The router might assign each device a different private IP address. The laptop can then send a document to the printer over the local network, while all three devices can also access the internet through the router.

Private IPv4 addresses are not directly routed across the public internet in the same way as globally routable public addresses. The router typically handles the translation needed for internet access.

Private addresses do not, by themselves, guarantee privacy or security. A device can still be vulnerable to malicious software, weak passwords, unsafe network settings, or other threats.

Public IP vs. Private IP: What's the Difference?

The key difference is where the address is used and how it participates in network communication.

These distinctions describe common IPv4 networking arrangements. IPv6 uses a different addressing structure, including globally routable addresses and addresses intended for local communication.

Neither address category automatically makes a device secure or insecure. Security depends on factors such as firewall rules, software updates, network configuration, and exposed services.

What Is IPv4?

IPv4, or Internet Protocol version 4, is one of the principal versions of IP used on the internet.

IPv4 uses 32-bit addresses, typically written as four decimal numbers separated by periods. Each number ranges from 0 to 255.

For example:

192.0.2.1

This format is called dotted-decimal notation. The address is divided into four sections, each representing eight bits.

IPv4 provides a theoretical address space of approximately 4.3 billion possible combinations. However, not all combinations are available for ordinary public use because various ranges are reserved for specific purposes.

One important example is 192.0.2.0/24. This block is reserved for documentation and examples, according to RFC 5737. Therefore, 192.0.2.1 is an illustrative address, not a typical public address assigned to an ordinary internet user.

IPv4 remains widely used because it is supported by an enormous amount of existing network equipment, software, and internet infrastructure.

Its limited address space is one reason IPv6 was developed.

What Is IPv6?

IPv6, or Internet Protocol version 6, is a newer version of IP designed to expand available addressing capacity and support the continued growth of interconnected networks.

IPv6 uses 128-bit addresses, providing a vastly larger address space than IPv4.

A valid illustrative IPv6 address is:

2001:db8::1

IPv6 addresses use hexadecimal notation and colon-separated groups. The double colon (::) can represent one or more consecutive groups of zeros, making long addresses easier to write.

The prefix 2001:db8::/32 is reserved for documentation and examples under RFC 3849.

IPv6 matters because its larger address space provides far more room for addressing network interfaces and organizing networks. It also includes other protocol changes described in the IPv6 specification, RFC 8200.

IPv4 and IPv6 can coexist on modern networks. Some connections support both versions, while others rely on one version or use technologies that help traffic move between different environments.

IPv6 does not automatically make an internet connection faster or more secure. Its performance and security depend on the network, implementation, and configuration.

What Is the Difference Between Static and Dynamic IP Addresses?

Static and dynamic describe how an IP address is assigned and whether it is intended to remain stable.

A static IP address is configured or assigned to remain consistent. Businesses may use static public addresses for certain servers, remote-access systems, or services that need a stable network endpoint.

A dynamic IP address is assigned through a configuration process and may change over time. Dynamic Host Configuration Protocol (DHCP), for example, can automatically assign IP addresses to devices on a local network. Internet providers may also assign public addresses dynamically.

Dynamic addressing is common in home networks because devices can receive their network configuration without users manually entering an address.

FeatureStatic IPDynamic IP
AssignmentIntended to remain stableAssigned automatically or through a changing allocation
Common usesServers and services needing a stable addressHome devices and many ordinary network connections
Can it change?Yes, if reconfigured or reassignedYes, although it may remain unchanged for long periods

A dynamic address does not necessarily change every time you open a website, reconnect to Wi-Fi, or restart your computer. An address may remain the same across multiple connections, depending on the provider, DHCP lease, and network configuration.

What Can Someone Learn From Your IP Address?

An IP address can provide useful information about a network connection, but it does not reveal everything about the person using it.

Depending on the address and available lookup data, someone may be able to determine:

  • Approximate geographic location: An IP lookup may indicate a country, region, or city, but the result can be inaccurate. IP geolocation is not a reliable way to establish an exact home address or physical location.
  • Internet service provider or organization: Registration and network information may associate an address with an ISP, company, hosting provider, or VPN service.
  • Connection-related information: Websites and online services may use IP addresses for security monitoring, rate limiting, analytics, fraud prevention, and approximate location-based decisions.

The accuracy of these details varies. Mobile networks, shared addresses, VPNs, proxies, and provider configurations can make a location estimate particularly imprecise. See MaxMind's explanation of IP geolocation accuracy.

An IP address alone does not ordinarily reveal someone's name, exact home address, complete browsing history, or precise physical location.

The context matters. An online service may combine an IP address with account information, activity logs, timestamps, or other available data to understand how its service is being used.

A VPN can also change the public IP address that websites typically observe. Traffic routed through a VPN server usually appears to originate from that server's public IP address rather than the user's original public IP address. For more details, see our beginner's guide to VPNs.

Does an IP Address Reveal Your Identity?

An IP address identifies a network endpoint used for communication; it does not automatically identify a particular individual.

For example, an address may be shared by multiple people in a household, an office, a public Wi-Fi network, or customers behind Carrier-Grade NAT.

In some circumstances, an IP address may be associated with a particular customer connection by examining additional records. Relevant information can include the address used at a specific time, account details, and records held by the internet service provider.

This does not mean an IP address alone proves who performed a particular online action. The reliability of any identification depends on the available evidence, the network arrangement, and the circumstances.

The practical takeaway is simple: an IP address can be a useful piece of information, but it is not a complete identity record.

How to Find Your IP Address

There are two common things people mean when they ask how to find their IP address: their public IP address, which internet services may see, and their local IP address, which their device uses on its connected network.

How to Find Your Public IP Address

The simplest method is to use a reputable IP-checking website.

  1. Open your web browser.
  2. Visit a trusted IP-checking service.
  3. Look for the public IPv4 or IPv6 address displayed on the page.

Depending on your connection, the service may show one address or both. If you use a VPN or proxy, it may display the address associated with that service instead of your original public IP address.

You do not need to install an application or provide personal information just to check your IP address.

How to Find Your Local IP Address

The steps vary by operating system and software version.

Windows 10 and Windows 11

  1. Open Start → Settings → Network & internet.
  2. Select Wi-Fi and your connected network, or select Ethernet if you use a wired connection.
  3. Look for IPv4 address in the network properties.

You can also see an IPv6 address if your network supports it. Microsoft's network settings guide provides additional details.

macOS

  1. Open the Apple menu and select System Settings.
  2. Select Network.
  3. Choose your connected Wi-Fi or Ethernet service.
  4. Open Details and look for the IP address in the network settings. For Wi-Fi, the address is available in the connection details.

See Apple's guide to Wi-Fi settings on Mac.

Android

  1. Open Settings.
  2. Go to Network & internet → Internet, or the equivalent network section on your phone.
  3. Select your connected Wi-Fi network.
  4. Look for the network details or IP address information.

Menu names vary between Android versions and manufacturers. Some devices place the address under additional network details. See Google Android Help: Connect to Wi-Fi networks.

iPhone

  1. Open Settings.
  2. Tap Wi-Fi.
  3. Tap the information button (ⓘ) beside your connected network.
  4. Look for IP Address under the IPv4 or IPv6 information, where available.

Apple documents the connected-network options in its iPhone Wi-Fi settings guide.

Remember that your device's local IP address and the public IP address seen by websites are usually different in a typical home IPv4 network.

Does Your IP Address Change?

Yes, an IP address can change, although it does not necessarily happen every time your device reconnects.

Your public IP address may change when your internet provider updates its address assignment, when you switch providers, or when your connection moves to a different network. Restarting a router may also result in a new public address, depending on the provider and configuration.

A device's private IP address may change when it reconnects to the local network or receives a different assignment from the router. However, routers can keep assigning the same private address to a device for extended periods.

Switching from home Wi-Fi to mobile data usually changes the network path and the public address seen by online services. Connecting through a VPN can also change the public address that a website observes.

For this reason, an IP address should not be treated as a permanent identifier of a person or device.

IP Address vs. MAC Address: What's the Difference?

IP addresses and Media Access Control (MAC) addresses serve different purposes in networking.

An IP address supports Internet Protocol communication and routing between network endpoints. A MAC address, in networks that use MAC addressing, helps identify an interface for communication on a local network link.

FeatureIP addressMAC address
Main purposeIP communication and routing between networksLink-layer communication on a local network
Typical formatIPv4: 192.168.1.20; IPv6: 2001:db8::1Commonly written as 00:1A:2B:3C:4D:5E
Can it change?Yes, depending on the assignment and configurationYes; some devices use randomized or locally administered MAC addresses
VisibilityIP addresses are carried in IP packets as traffic crosses networksMAC addresses are used on the relevant local link and are not normally carried unchanged end to end across routers

For example, when a laptop sends data to a server on another network, the IP destination identifies the network endpoint the traffic is trying to reach. The link-layer addressing used to send the packet to the next hop is a separate part of the process.

MAC addresses should not be assumed to be universally permanent or globally visible identifiers. Modern devices and operating systems may use address randomization to reduce tracking across Wi-Fi networks.

Frequently Asked Questions About IP Addresses

1. What is an IP address in simple terms?

An IP address is a numerical network address that helps identify where data comes from and where it needs to go. It allows devices and network equipment to exchange information.

2. Why does every device need an IP address?

A device needs an appropriate IP address on a network when it communicates using IP. A device may have more than one address or network interface, and not every address must be globally routable.

3. Is an IP address the same as a physical address?

No. A physical mailing address identifies a location for postal delivery. An IP address identifies a network endpoint for digital communication and does not necessarily identify a precise physical location.

4. What is the difference between a public and private IP address?

A public IP address can be used for globally routed internet communication. A private IPv4 address is used within private networks, such as a home or office network.

5. Can two devices have the same IP address?

Yes, devices can share a public IPv4 address when they access the internet through NAT. However, duplicate addresses on the same network segment where unique addresses are required can cause connectivity problems.

6. Can an IP address identify a person?

Not reliably by itself. An IP address may be associated with an internet connection, but additional information is generally needed to connect it to a particular individual.

7. Does an IP address reveal my exact location?

No. IP geolocation can estimate a general location, but the result can be inaccurate and should not be treated as an exact physical address.

8. Does my IP address change when I restart my router?

It might, but it is not guaranteed. Your provider's address-assignment policies and your router's configuration determine whether your public IP address changes. Your device's local address may also remain the same.

9. What is the difference between IPv4 and IPv6?

IPv4 uses 32-bit addresses and commonly displays them as four decimal numbers separated by periods. IPv6 uses 128-bit addresses and displays them as hexadecimal groups separated by colons.

10. Is it safe to share your public IP address?

A public IP address is not normally a secret credential like a password. However, it can provide information about a network connection and may be useful to someone investigating exposed services or attempting unwanted network activity. Avoid publishing it unnecessarily and keep your router, firewall, and connected devices properly configured.

Conclusion

An IP address is a fundamental part of how devices communicate over networks. It helps identify the source and destination of data, allowing routers and other network equipment to forward information toward the appropriate endpoint.

Public and private IP addresses serve different roles, while IPv4 and IPv6 provide two different addressing systems. Addresses may be static or dynamic, and their assignments can change depending on the network and provider.

Although an IP address can reveal useful information about an internet connection, it does not automatically identify a person or provide an exact physical location.

For beginners, the most important point to remember is that an IP address helps data find its destination, but it does not tell the whole story about who is online or where they are.
